📱 How to open a .apkg on Android (share sheet)
  1. Open this site in Chrome and tap Install app above (or menu → Add to Home screen). Android only lists installed apps in the share sheet.
  2. Open the Files app (or Downloads), long-press the .apkg file → Share.
  3. Pick Anki Inspector — the deck opens by itself.

Not in the list? Android only lists the app when it was installed as a real web app (Chrome → Install app / Add to Home screen with a manifest — installs from other browsers are plain shortcuts and never share). The share registration is baked in at install time, so after this update (v3.5) you must either launch the installed app once and give Chrome up to a day to refresh it, or remove the icon and install again for the new registration to take hold. Also check ⋮ More / “Android Share” in the sheet — MIUI/One UI hide web apps there. Meanwhile, Choose file above always works, including from inside AnkiDroid’s export dialog.

A deck that only shows a “Please update to the latest Anki version” note is a modern Anki export — this app reads those directly (no re-export needed). Reload the app once if you still see that note, so the newest version installs itself.
